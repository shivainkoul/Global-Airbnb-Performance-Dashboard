<H1>GLOBAL AIRBNB PERFORMANCE DASHBOARD</H1>
<H2>1. PROJECT TITLE</H2>

 Global Airbnb Performance Dashboard

## <H2>2. SHORT DESCRIPTION</H2>

A Power BI dashboard for analyzing **Global Airbnb Performance**. It provides insights into listings, cities, property types, pricing, ratings, reviews, seasonality, and host verification to understand market performance and customer behavior.

## <H2>3. TECH STACK </H2>

• Power BI Desktop
<br>•  Power Query
<br>•  DAX
<br>•  Data Modeling
<br>•  .pbix / .pbit / .png

## <H2>4. DATA SOURCE</H2>

**Source:** mavenanalytics.com

The dataset includes Airbnb-related information such as:

• Listing details
<br>• City and location
<br>• Property type / Room type
<br>• Host information
<br>• Reviews and ratings
<br>• Pricing
<br>• Superhost status
<br>• Host verification
<br>• Listing dates and availability

## <H2>5. HIGHLIGHTS </H2>

## i. Business Problem

Global Airbnb data contains a large number of listings, hosts, reviews, cities, and property types, making it difficult to quickly identify market trends, pricing patterns, customer preferences, and host performance.

## ii. Goal Of The Dashboard 

• Track the growth of Airbnb listings
<br>• Compare market share across cities
<br>• Analyze pricing by room type
<br>• Understand customer ratings and reviews
<br>• Identify seasonal review patterns
<br>• Analyze host verification and trust
<br>• Compare property and room-type performance
<br>• Support data-driven business decisions
